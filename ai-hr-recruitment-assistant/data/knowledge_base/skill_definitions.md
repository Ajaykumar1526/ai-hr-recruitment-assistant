# Skill Definitions & Proficiency Levels

## Proficiency Levels
- **Beginner**: Familiar with basic concepts, has completed tutorials or coursework, limited hands-on project use.
- **Intermediate**: Has applied the skill in at least one real project or job, can work with moderate guidance.
- **Advanced**: Has deep, repeated hands-on experience, can debug complex issues and make design decisions independently.
- **Expert**: Recognized go-to person for the skill, mentors others, contributes to best practices or tooling.

## Common Data/AI Role Skill Clusters
- **Programming**: Python, SQL, R, Java, JavaScript
- **Data Analysis**: Pandas, NumPy, Excel, data visualization (Matplotlib, Seaborn, Power BI, Tableau)
- **Machine Learning**: scikit-learn, model evaluation, feature engineering, TensorFlow/PyTorch for deep learning
- **Data Engineering**: ETL pipelines, Airflow, Spark, cloud data warehouses
- **Cloud & DevOps**: AWS/Azure/GCP, Docker, CI/CD, Git version control
- **Soft Skills**: Communication, stakeholder management, problem-solving, teamwork

## Notes for Matching
- Related tools (e.g., "JavaScript" and "TypeScript", "Power BI" and "Tableau") often indicate transferable skill,
  even if not an exact match — treat these as partial matches, not automatic strong matches.
- A candidate listing a skill in "projects" but not "skills" should still be credited if the usage is clear and recent.
