# Common Role Requirement Baselines

## Data Analyst
- Core skills: SQL, Excel, Python (Pandas), data visualization, statistics fundamentals.
- Typical minimum experience: 0-2 years for junior, 2-4 years for mid-level.
- Strong candidates can translate business questions into data queries and clear visual/narrative insights.

## Python Developer
- Core skills: Python, OOP fundamentals, REST APIs, Git, testing frameworks (pytest), SQL basics.
- Typical minimum experience: 0-2 years for junior, 2-5 years for mid-level.
- Strong candidates show clean code practices, debugging ability, and experience with at least one web/backend
  framework (Flask, Django, FastAPI) or applied ML stack (scikit-learn, pandas, numpy).

## Machine Learning Engineer
- Core skills: Python, scikit-learn/TensorFlow/PyTorch, model evaluation, data preprocessing, deployment basics.
- Typical minimum experience: 1-3 years for junior/mid-level.
- Strong candidates can discuss trade-offs (bias/variance, precision/recall) and have deployed at least one model.

## Data Engineer
- Core skills: SQL, Python, ETL/ELT pipelines, a cloud platform (AWS/Azure/GCP), workflow orchestration (Airflow).
- Typical minimum experience: 1-3 years for junior/mid-level.
- Strong candidates understand data modeling, pipeline reliability, and basic data quality practices.
